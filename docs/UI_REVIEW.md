# 阅读界面细节检查 · 2026-10-29

页面保留暖纸面、衬线页标题、墨色操作和少量朱红。将阅读当作翻阅读本，侧栏与正文随文档自然展开；不以隐藏滚动条的方式裁切内容。

## 本轮调整

- 移除侧栏、正文和手机书架列表的独立滚动容器，全文、解析与讨论均由整页承载。
- 手机上进入已有故事时收起创作与书架；可随时展开，五条最近读本全部可达。主动生成新故事时保持创作与进度可见。
- 阅读器窄于42rem时，页码收成原生选页控件；宽纸面保留逐页目录。前后翻页与方向键继续可用，翻页后回到新页开头并定位键盘焦点。
- 分享设置在阅读器顶部就近展开，宽屏两栏、窄屏单栏；保持复制、撤销和关闭后的焦点与滚动位置。
- 调整侧栏末尾留白、导航点击范围、说明字号、关闭按钮和长标题换行，保留原有文字书封、书架层板与图文关系。

## 验证范围

本地隔离浏览器覆盖首页、创作欢迎页、书架、长篇文字、漫画、解析、作答反馈、分享未发布/已发布/无法读取、作者预览、分享访客、失效分享、登录/注册/恢复及恢复码。主要为1440px桌面和390px手机，并检查320px、768px、1920px。

56项布局及交互检查通过，保留38张页面实图。检查全文末尾可见、无横向溢出、内部无滚动容器、手机展开及选页、翻页焦点、分享关闭焦点、减少动态效果和页面错误。私人数据与账户状态由隔离样例模拟；这些结果不等于真实账户性能测量，也不创建线上任务或调用模型。
