# 书架加载优化

2026-10-28。书架过去在每次重新进入时验证登录，再下载全部故事、分页与解析；返回阅读页后，列表也随组件卸载而丢失。

现在书架使用受账户验证保护的 `GET /learn/api/library`，只返回书名、开篇、日期、状态和封面地址。完整故事在翻开时从原详情接口取得；原完整列表接口保留兼容。列表响应包含实际账户名，前端拒绝不属于当前登录账户的结果，保持 `Cache-Control: no-store`。

普通的书架、阅读与新故事导航在同一页面完成。已确认账户的书架列表只保存在当前页面内存里，返回时先显示，再后台核对；不会把私人故事写入浏览器持久缓存。注销、会话失效或账户变化会清空该缓存。新标签页与完整刷新仍先验证身份。

验证：Studio 85项测试、公开版87项测试和两边构建通过。新增真实本机 HTTP 测试检查未登录拒绝、跨账户隔离、开篇长度、完整详情保留、读取不改保存数据，以及合成长篇的封面响应小于完整列表的20%。这不是生产数据的体积测量。

实际本地浏览器32项检查通过，查看了桌面、平板和手机排版。人为阻止后台接口返回时，返回书架约40ms、从页首进入约46ms即可显示已有列表；导航未重载页面或重复验证会话。这是本机测试结果，不是公网首访耗时。另检查了翻开、完整分页、返回焦点、减少动态效果、账户不匹配时清空缓存，未发现页面脚本错误。

同日已上线。公网实际构建通过40项浏览器检查；真实匿名访问确认新接口需要登录、预置文字/漫画和解/议可读、没有字体下载，私人交互使用隔离GET模拟。公网构建的模拟暖缓存导航为55–62ms；没有以生产账户进行测速或创建测试故事。部署后核对既有故事原始字节、账户/会话/分享逻辑指纹、素材与旧服务均保持完整。
