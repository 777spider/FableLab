# 运行与部署边界

当前默认分支是个人本机运行的 BYOK 开源版。作者不配置通用付费 Key。使用者自行运行 Node.js 服务、配置自己的文字和生图接口。默认监听 `127.0.0.1:4318`，不提供登录、书架、邀请或公开分享接口，也不初始化旧账户数据库。

运行方式见 [本地指南](QUICKSTART.md)。没有云服务订阅、域名、Nginx、数据库或生产密钥的前置要求。

## 数据生命周期

- 文字/生图 Key 和验证状态在运行进程的内存中。正常服务重启后清空。
- 同一浏览器通过 HttpOnly、SameSite=Strict 的匿名会话 Cookie 隔离当前配置和工作内容。这不是实名账号，不能跨设备恢复。
- 任务检查点与图片写入应用专用临时目录，保证页面断开后仍能在当前进程中继续。正常关闭删除。强制结束可能留下临时内容，不含已保存的 Key，也不会在下次启动时自动读取。
- 停止服务前导出要保留的文字。这里没有持久书架、云同步或跨重启恢复承诺。
- 多人共享一个远程进程、持久备份和服务器重启续跑不在此版的支持范围。

## 不要直接改成公网服务

启动入口仅允许回环地址，HTTP API 检查 Host、Origin、JSON 内容类型并隔离媒体。它面向使用者自己电脑上的网页，不是一套完整的多租户公网网关。不要单靠端口转发或反向代理将其暴露给不受信任的人。

若要进一步开发多人托管，应先设计 HTTPS、身份与会话生命周期、SSRF/DNS 地址校验、并发与调用额度、上传/下载限制及数据保留政策，再单独审查。当前版本不声称已经完成这些工作。

## 原完整平台

标签 `full-studio-20261029` 保留原有完整 Studio。旧账户、邀请码、分享、持久任务和生产部署说明适用于该版本。当前入口 `server/index.ts` 改用 `createLiteApp`，不引用原 `createApp`、`AuthService`、`ShareService` 或 `EcnuProvider`。

本次公开版发布不会修改作者既有的个人线上平台、账户或故事数据。
